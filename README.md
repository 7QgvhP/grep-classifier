# C-Grep Classifier

C言語ソースコードに対してキーワード検索（grep）を行い、その結果を `web-tree-sitter` による構文解析（AST）を用いて「入力」「出力」「定義」「コメント」「その他」に高精度に分類して表示するVS Code拡張機能です。

単なる文字列一致ではなく、キーワードが**代入の左辺なのか右辺なのか**、**宣言なのか参照なのか**を構文木から判定するため、「この変数はどこで書き換えられているのか」を短時間で把握できます。

## 分類カテゴリ

| カテゴリ | 意味 | 例 |
|---|---|---|
| 📥 **入力** | 値が読み取られている箇所 | `x = hoge;` / `func(hoge)` / `if (hoge > 0)` |
| 📤 **出力** | 値が書き込まれている箇所 | `hoge = 10;` / `hoge++;` / `scanf("%d", &hoge)` |
| 📝 **定義** | 宣言・定義されている箇所 | `int hoge;` / `#define hoge 1` / `void hoge(void) {}` |
| 🗨️ **コメント** | コメント内に出現している箇所 | `// hogeの説明` |
| ❓ **その他** | 上記のいずれにも該当しない箇所 | — |

判定条件の詳細は [docs/classification_spec.md](docs/classification_spec.md) を参照してください。

## 主な機能

* **高精度データフロー分類**: 配列アクセス（`hoge[0]`）や構造体メンバアクセス（`hoge.member`、`ptr->member`）、アドレス渡し（`&hoge`）を区別し、代入の左右辺・宣言・条件式のどこに位置するかに応じて分類します。
* **サイドバー常駐の検索窓**: アクティビティバーの「C-Grep Classifier」から、キーワードを入力して `Enter` で検索します。
* **単語全体に一致（Match Whole Word）**: 検索窓右のトグルボタンで、部分一致と完全一致を切り替えられます（例: `hoge` で `hoge_max` をヒットさせない）。
* **カテゴリ／ファイル別の階層表示**: 分類カテゴリごと、さらにファイルごとにアコーディオンでグループ化して表示します。
* **キーボード巡回とプレビュー**: `↑` `↓` キーで一致箇所を順に選択でき、選択と同時にエディタ上に該当箇所が表示されます（フォーカスはサイドバーに残ります）。`Enter` でエディタ側へフォーカスを移します。
* **ハイライトジャンプ**: 項目を選択すると該当ファイルが開かれ、キーワードの範囲がテーマ色に連動した色でハイライトされます。
* **文字コードの自動追従**: VS Code の `files.encoding` 設定を参照するため、Shift_JIS や EUC-JP のファイルも解析できます。
* **未保存バッファへの対応**: 編集中で未保存のファイルは、ディスク上の内容ではなくエディタ上の内容が解析されます。

## 使用方法

### サイドバーから検索する

1. アクティビティバーの「C-Grep Classifier」アイコンをクリックします。
2. 検索窓にキーワードを入力し、`Enter` を押します。
3. カテゴリごとに分類された結果が表示されます。項目をクリック、または `↑` `↓` キーで選択すると該当箇所へジャンプします。

### 選択した単語で検索する

エディタ上で単語を選択した状態で `Alt + Q` を押すと、その単語で検索が実行され、結果がサイドバーに表示されます。
何も選択していない場合は、サイドバーにフォーカスが移動します。

| 操作 | キー |
|---|---|
| 選択テキストで検索 / サイドバーへフォーカス | `Alt + Q` |
| 検索の実行 | `Enter`（検索窓） |
| 一致箇所の巡回 | `↑` `↓` |
| エディタへフォーカスを移す | `Enter`（結果リスト） |

コマンドパレット (`Ctrl + Shift + P`) から `C-Grep: データフロー分類検索を実行` を実行しても同じ動作となります。

## 設定

VS Code の設定画面で `C-Grep Classifier` を検索すると、以下の項目を変更できます。

| 設定項目 | 既定値 | 説明 |
|---|---|---|
| `cGrepClassifier.includePattern` | `**/*.{c,h}` | 検索対象とするファイルのglobパターン。`.inc` などの独自拡張子を扱う場合に変更します。 |
| `cGrepClassifier.excludePatterns` | `["**/node_modules/**"]` | 検索対象から除外するglobパターンの一覧。ビルド生成物や外部ライブラリの除外に使用します。 |
| `cGrepClassifier.useDefaultExcludes` | `true` | VS Code標準の除外設定（`files.exclude` / `search.exclude`）も併せて適用します。 |

## 動作要件

* VS Code `1.75.0` 以降

## 開発

```bash
npm install       # 依存関係の取得
npm run compile   # TypeScript のビルド（out/ へ出力）
npm run watch     # 変更監視ビルド
```

デバッグ実行は `F5`（Run Extension）で行います。

### ディレクトリ構成

| パス | 内容 |
|---|---|
| `src/extension.ts` | 拡張機能本体（Webview View Provider・検索の実行） |
| `src/matcher.ts` | AST走査と一致箇所の抽出 |
| `src/classifier.ts` | データフロー分類ロジック |
| `src/types.ts` | 型定義とカテゴリ定義 |
| `media/` | Webview の HTML / CSS / JavaScript |
| `bin/` | tree-sitter および C言語パーサーの WASM |
| `docs/` | 分類ロジックの技術仕様書 |
