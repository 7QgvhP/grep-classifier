# C-Grep Classifier

C言語ソースコードに対してキーワード検索（grep）を行い、その結果を `web-tree-sitter` を用いて「入力」「出力」「定義」「コメント」「その他」に高精度に分類して表示するVS Code拡張機能です。

## 主な機能

* **高精度データフロー分類**: 配列アクセスや構造体メンバアクセス、アドレス渡しを区別し、キーワードが代入の左右辺・宣言・条件式のどこにあるかに応じて正確に分類。
* **ツリービュー表示**: サイドバーの専用ツリービューで、カテゴリごとに結果を整理して表示。
* **ハイライトジャンプ**: ツリー内のアイテムをクリックすると、エディタ上で該当ファイルが開かれ、キーワードの範囲が自動的に選択ハイライトされます。

## 使用方法

1. コマンドパレット (`Ctrl + Shift + P`) から `C-Grep: データフロー分類検索を実行` を起動します。
2. 検索キーワードを入力します。
3. アクティビティバーに追加された「C-Grep Classifier」のアイコンから結果を確認します。
